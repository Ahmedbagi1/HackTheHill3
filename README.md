# HackTheHill3 
Civic OS
One search, every level of government.
CivicOS is a civic action hub that solves government website fragmentation. Instead of looking across dozens of municipal, provincial, and federal websites, people describe a life event in plain language, such as "I lost my wallet," "We're having a baby," "I'm moving provinces," and CivicOS returns a single, consolidated checklist covering every office they actually need to deal with, plus an in-app form wizard to act on it and a voice companion to have it read aloud. 

Built for Hack the Hill III.
